## 2. Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **Language**: TypeScript (Strict Mode)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://motion.dev/)
- **Icons**: [Lucide React](https://lucide.dev/) + Custom Vector Brand Icons
- **Deployment Target**: [Vercel](https://vercel.com/) (Production Ready)

## 4. Getting Started

### Prerequisites
- Node.js 18.18 or later
- npm 9 or later

### Installation

```bash
# Clone repository
git clone <your-repo-url>
cd Website

# Install dependencies
npm install

# Run local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

## 5. Scripts

## 7. Vercel Deployment Guide

1. Push your code to GitHub:
   ```bash
   git add .
   git commit -m "feat: complete 10-page enterprise website for MR.Engineers"
   git remote add origin https://github.com/<your-account>/mr-engineers.git
   git push -u origin main
   ```
2. Navigate to [vercel.com](https://vercel.com/new).
3. Import your GitHub repository.
4. Next.js App Router will be detected automatically.
5. Click **Deploy**.
